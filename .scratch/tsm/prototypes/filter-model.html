tsm — filter-model prototype (T-filter)

Drive tsm's three orthogonal filters on real session data. Everything is in-memory; this is a mock of the filter logic, not the TUI look (that's the T-layout prototype).

Question this answers: three filters stack with AND — scope (this project ↔ all), lifecycle (active ↔ archived), search (case-insensitive substring over title + first message). Default landing = this project ∧ active ∧ no search, sorted by recency. Search is a MODE: / enters live-filter, Enter commits & keeps the filter (back to normal so p / Tab / Space work on the filtered set), Esc clears. Selection is kept by id in a set and is silently preserved across filtering — a hidden selected row stays selected.
